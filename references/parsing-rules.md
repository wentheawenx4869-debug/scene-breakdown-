# 剧本拆场解析规则

本文件是 scene-breakdown 技能的解析细节。按此规则把剧本拆成「场」，生成顺场景表与分场景表。

## 一、集识别（可选）

- 剧本若含多集，先按「第X集」「S01E02」「EP.3」等标记切分；拆场时可在「场号」前带集前缀（如 `1-01`），或另做集列。
- 单集剧本/电影/短剧：无集标记，直接按场拆，无需集列。

## 二、场头识别

场头是场景开始的标志行，常见格式（中英文均覆盖）：

- `1. 内景 许念家 清晨`
- `2 外 街道 夜`
- `第3场 内景 办公室 白天`
- `INT. COFFEE SHOP - DAY`

识别要点：一行开头出现**场号**（行首数字 1-4 位，或「第X场」/「Scene X」），随后可含内/外标记，再是**地点**，末尾常是**日/夜/晨/暮等气氛词**（气氛词非必需，缺失时标注待确认）。

从场头提取要素：
| 要素 | 识别 | 归一取值 |
|---|---|---|
| 场号 | 行首数字或「第X场」 | 数字，保持原序 |
| 内/外 | 内/内景/INT、外/外景/EXT | 内 / 外（按该行次场景实际取） |
| 地点 | 内/外标记之后、气氛词之前的连续文字 | 拆主场景/次场景 |
| 气氛 | 日/白天/DAY、夜/傍晚/黄昏/清晨/黎明/NIGHT | 归一为 日/夜/晨/昏，单列为「气氛」列 |

## 三、主场景 / 次场景拆分（主取大地点、次取细分机位点）

**主场景取大地点**：许念家、街道、银杏树下、公园、银杏路口等（内/外景边界清晰）。
**次场景取该地点内的细分机位点**：卧室/客厅/厨房/楼下/街上/转角等。

- 若地点含分隔（`·`、`-`、`—`、`／`、逗号、空格）：**前半为主场景**，**后半为次场景**。
- **剧本未写明次场景时从动作推断**：床上惊醒→卧室；母亲切菜→厨房；追至路口→斑马线路口；冲出楼门→楼下；在街上奔跑→街上；转角跪倒→转角。
- **多个次场景**时，每个次场景独立成一行，各自为独立机位/灯位单元。
- 拿不准时主场景取大粒度地点，次场景留空并备注。

### 气氛归一与单列（服务实际拍摄）

- 气氛取值归一：**日 / 夜 / 晨(清晨) / 昏(黄昏)**。
- **气氛变化必单列**：一场内出现「跳切至夜」「日至夜」「清晨→黄昏」等 → 拆成多个气氛行，各行的「气氛」填对应值，并在「内容」里注明变化点。
  - 例：`02 外景 银杏树下 日至夜` → 拆两行：一行气氛=日（白天蹲树下不接电话）、一行气氛=夜（跳切至夜，路灯亮，接电话被告知母亲出事）。
- 场头缺气氛标记时，保留该行并标「待确认」，不臆造。

## 四、场边界判定

- **新场头出现** → 上一场结束、新场开始。
- 正文中的转场提示（「（转场）」「闪回」「CUT TO:」）不作为新场，除非该行同时含场头要素。
- 无场头的连续段落：并入最近场头之后；确属独立场景而缺场头，标记「待确认场头」。

## 五、角色清单（决定演员列，动态列）

**拆场前先通读全剧，提取全部出场角色，去重后为每个角色建一列。**
- **对白角色**：`角色名：台词` 或 `角色名（动作）：台词` → 提取角色名。
- **动作/出场角色**：`许念起身`、`父亲走进来`（行首角色名＋动词）→ 结合上下文判定；不确定并入内容并标注。
- **叙述性代词**（他/她）不单独成列。
- **画外音**：`(V.O.)` / `(O.S.)` 归入原角色列（如「父亲(电话)」仍记入「父亲」列）。
- **次要角色**（如司机、路人甲乙）：确有戏份就独立成列；仅路过一次可并入「群演」。
- 演员列顺序按**首次出场先后**或戏份多少排列；出场填**最能代表该角色的一字**（许念→念、母亲→母、父亲→父、司机→司、群演→群），未出场留空。不填 √（只打勾不专业）。
- 若用户提供「角色—演员」映射表，列名可用演员名；否则用角色名（列内仍填代表单字）。

## 六、群演识别

- 剧本中出现「群众」「群演」「围观的人」「路人」「腰鼓队」「打急救电话的人」「孩子及其母亲」等群体/临时角色 → 建「群演」列。
- 明确数量则用原文数字；无数量写群演类型说明（如「路过行人」「腰鼓队」）；无群演描写则留空。
- 「群演」列值与普通演员列不同：填**说明/人数**，而不是 √。

## 七、服化 / 道具提示（仅供参考）

- **服化提示**：从该场角色穿着（「深色棉衣」）、化妆（「化着浓妆」）、状态（「衣袖血迹」）等描写推断，标「仅供参考」。
- **道具提示**：从该场手持物、陈设物（「旧表」「布包」「还款收据」「账本」「空瓶」「手机」）推断，标「仅供参考」。
- 无依据不凭空添加；确属该场才记入。

## 八、镜号规则

- 剧本内有明确分镜标记（「镜头 N」「#N」「CUT」）：在每行内按标记从 1 重新编号。
- 剧本无分镜标记：每行（拆行后）默认 1 个镜号，全剧本按**剧本出现顺序**连续编号（第1行→镜1、第2行→镜2…）。
- 用户指定其他编号方式时按其执行。

## 九、常见歧义与处理

| 情况 | 处理 |
|---|---|
| 场号跳号或重号 | 保留原号，质检提示；可另加备注 |
| 场号顺序倒置（如 08 在 07 前） | 按剧本出现顺序排，保留原场号 |
| 场头缺日/夜标记 | 保留该场，标记待确认，不臆造 |
| 场景内转场 / 闪回 / 画外音 | 归入当前场，内容保留 |
| 一场跨多页 | 忽略分页，按场头聚拢 |
| 同一主场景连续多场 | 顺场景表仍按场序分行；分场景表按主场景合并一组 |
| 相似场景命名（「卧室」vs「许念卧室」） | 分场景表分组时可归并为同一主场景 |

## 十、输出保真

- 「内容」为**一句话短句 = 人物 + 动作 + 主要情节**；不插入引号对白（`“...”` 一律不进表格）。
- 顺场景表按剧本出现顺序（场号原序）。
- **分场景表排序规则**：按主场景分组；**组按拍摄量（行数）从多到少排**（拍得最多放最前、拍得最少放最后）；**组内按剧本场次顺序排**（不随意调整剧本场次顺序）。
- 演员每人一列，**表头（标题行）竖排写完整角色名**（每字一行、窄列宽+自动换行），列内填代表单字；群演列填说明/人数。
