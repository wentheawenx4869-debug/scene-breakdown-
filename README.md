# Scene Breakdown（剧本拆场 / 拍摄统筹表）

> 把影视分场剧本自动分解为四张表：**顺场景表、分场景表、演员表、场景表**，专为制片人 / 副导演 / 统筹 / 场记的实际拍摄调度而设计。

## 它能做什么

输入剧本（Word `.docx`、PDF、Markdown、纯文本，或直接粘贴文本），输出四张表：

- **顺场景表**：按剧本出现顺序一行一行排，即生产调度用表；
- **分场景表**：按大场景（地理相近的地点合并成组）分组，供按景集中拍摄/转场统筹；
- **演员表**：每个角色的画像（人物关系 / 年龄 / 性格）；
- **场景表**：每个场景的描述（结合机位 / 灯位 / 调度等影视实拍知识点）。

每行是一个独立拍摄调度单元（机位 / 灯位）。

表格列结构：

`序号 | 场号 | 镜号 | 主场景 | 次场景 | 内/外 | 气氛(日/夜/晨/昏) | 内容 | <演员一人一列> | 服化提示(仅供参考) | 道具提示(仅供参考)`

- 角色列（演员列）：**表头竖排写完整角色名**（如 主角A / 母亲 / 父亲 / 司机 / 群演，每字一行 + 自动换行），列内填最能代表该角色的一字（A / 母 / 父 / 司 / 群）。
- 四张表一并产出。

## 核心规则（一切为实际拍摄服务）

- **主场景取大地点**（如 主角家 / 街边 / 公园），**次场景取细分机位点**（卧室 / 客厅 / 厨房 / 楼下 / 路口 / 转角）；剧本未写明次场景时**从动作推断**（床上惊醒→卧室、切菜→厨房、追至路口→路口）。
- **气氛变化单列成行**：剧本出现「跳切至夜」「日至夜」等，拆成多个气氛行（日行、夜行），各行为独立布光/机位单元，不在内容里一笔带过。
- **演员一人一列**，出场填**最能代表该角色的一字**（不填 √）。
- **内容列**：一句话短句 = 人物 + 动作 + 主要情节，不插入引号对白。
- **分场景表**：按大场景分组（家 / 车祸现场 / 公园等地理相近合并），组内按场号顺序，组间按拍摄量从多到少。
- **编号**：场号纯数字（1、2、3…不补零）；镜号场内序号（每场从 1 起）。

## 表格格式规范

- **全部单元格居中**（水平 + 垂直）。
- **列宽**：每列仅比该列文字最宽处略宽，需换行时用自动换行，不设过宽列。
- **列标题（第一行）**：蓝色填充 + 白字加粗，数据区白底、不用大面积底色。

## 安装

克隆本仓库，把 `scene-breakdown/` 文件夹放进对应平台的 skills 目录：

| 平台 | 安装路径 |
|---|---|
| Claude Code | `~/.claude/skills/scene-breakdown/` |
| Cursor / 通用 Agent Skills | `~/.agents/skills/` 或项目内 `.agents/skills/` |
| 豆包（Doubao Work） | `workspace/.user_skills/scene-breakdown/` |
| 其它支持 `SKILL.md` 的 Agent | 放入其 skills 根目录即可 |

## 使用

对 AI 助手说类似的话即可触发：

- 「帮我拆场，生成顺场景表」
- 「把这份剧本分解成拍摄统筹表」
- 「按剧本做场景清单，标出主/次场景、内/外、日/夜」
- 「出演员表和场景表」

默认交付飞书在线表格 + Excel 双份；也可以只要 Excel 或只要在线表。

## 扩展

这个技能是可复用的模板：每拿到新剧本，把剧本交给启用本技能的 AI 即可自动出四张表。你对剧本、导演、摄影的理解（如某个场景的布光、机位偏好、调度思路）可以直接补充进 `references/parsing-rules.md` 或作为新增参考文档，技能会长期沿用你的口径。
